# Cofre de Segredos

Site em Python (Flask) sobre segurança da informação.

## O que faz
- Cifras por substituição (César e alfabeto embaralhado): codifica e decodifica mensagens
- Hash de senhas: SHA-256 puro vs PBKDF2 com sal
- Simulador de força bruta: mostra quanto tempo leva pra quebrar senhas curtas
- Medidor de força de senha com dicas de boas práticas

## Como rodar
pip install flask
python app.py

Depois abra http://127.0.0.1:5000
